# 局域网电量监控

在同一局域网内,查看各台安装了本 App 的安卓手机的实时电量。
**服务器主动拉取**:只有在你打开网页 / 刷新时,服务器才现场去各手机查询一次电量。

## 结构

```
Server/       Flask 服务器(跑在常开的 Win11 电脑上)
AndroidApp/   安卓客户端(Android Studio 工程)
```

## 工作原理

1. 手机 App 启动后跑一个微型 HTTP 服务(端口 8080),只暴露 `GET /battery`。
2. 手机把「设备名 + 端口」注册到 Flask 服务器,IP 由服务器从请求里自动获取。
3. 你打开 `http://<Win11的IP>:5010`,服务器并发去每台手机 `GET /battery` 拉一次实时电量并展示。

## 一、启动服务器(Win11)

```powershell
cd Server
pip install -r requirements.txt
python app.py
```

先查本机局域网 IP(记下来填进手机 App):

```powershell
ipconfig   # 看 "IPv4 地址",通常是 192.168.x.x
```

浏览器打开 `http://<该IP>:5010` 就是仪表盘。

> 首次可能被 Windows 防火墙拦截,弹窗时勾选"专用网络"允许;
> 或手动放行 5010 端口(入站规则)。

## 二、编译安卓 App

1. 用 **Android Studio** 打开 `AndroidApp` 文件夹,等待 Gradle 同步。
2. 连上手机(开启 USB 调试)或用模拟器,点 Run 安装。
3. App 里填:
   - **服务器 IP** = 上面 Win11 的 IP(如 `192.168.1.100`)
   - **本机显示名称** = 随意,比如"爸爸的手机"
4. 点「启动并注册」,顶部通知栏会常驻一个服务通知。
5. 回到电脑刷新网页,就能看到这台手机的电量。多台手机重复即可。

## 常见问题

- **网页里手机显示"离线"**:手机和电脑要在同一 WiFi;确认 App 服务在跑(通知栏有常驻通知);部分手机需给 App 关闭"电池优化 / 后台限制",否则息屏后服务被杀。
- **IP 变了**:手机会每 5 分钟自动重新注册;也可回 App 重新点一次「启动并注册」。
- **换成开机自启**:可给手机 App 加一个开机广播接收器自动拉起服务(当前需手动点一次启动)。
